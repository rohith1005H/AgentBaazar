# AgentBaazar

Agent-ready commerce for every small store, on PayPal.

AgentBaazar turns any product catalog into a store that AI shopping agents can buy from using PayPal's agentic commerce cart contract, ships a buyer agent that shops those stores, and gives the merchant a live console to watch and operate agent-sourced orders.

Built for the [PayPal AI Hackathon](https://paypalaihackathon.devpost.com/). Work in progress; full docs land with the first release.
